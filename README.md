## 操作
キーボード：← → / A D で移動、↑ / W / スペースでジャンプ、R でやり直し
タッチ：ボタン・スティック・フリー操作から選択
ゲームパッド：十字キー/左スティック、A・Bでジャンプ、START でやり直し
